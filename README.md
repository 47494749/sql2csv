# sql2csv by Luigi Origa

**sql2csv** is a simple tool for converting sql dump to csv.

Implemented natively in C++ and intended to run on **Windows**.  

---

## Project Status

> **Under Development**
>
> This project is still experimental — no stable release or complete documentation yet.  
> Functions, internal structures, and output format may change frequently.
>
> Run `sql2csv -h` to check available options and newly added features.

## Usage

```bash
./sql2csv -i [path_to_sql]
./sql2csv -h
